# FoodRescue mockup-inspired build

Install requirements with `pip install -r requirements.txt` and run `streamlit run app.py`.

The homepage uses the original clean produce photograph rather than a cropped mockup. The default Streamlit sidebar is hidden, and navigation is across the top. Demo Studio provides two fictional user perspectives; use it to create a sample donation as a business and request it as a food bank. Reset before presenting. No food distribution or impact is claimed.
